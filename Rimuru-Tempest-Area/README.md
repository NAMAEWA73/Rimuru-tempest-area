# Rimuru Tempest Area

Aplikasi Android untuk:
- Rental 6 unit PS3
- Timer rental
- Tarif Rp5.000/jam
- Rumah makan
- Makanan dan minuman
- Keranjang pesanan
- Tagihan gabungan
- Pembayaran tunai
- Pembayaran QRIS
- Laporan pendapatan

## Cara menjalankan
1. Buka folder ini menggunakan Android Studio.
2. Tunggu Gradle Sync.
3. Jalankan pada HP Android atau emulator.

## GitHub
Upload seluruh proyek ke repository GitHub.
GitHub Actions akan mencoba membuat APK debug otomatis.

## Catatan
Versi ini adalah versi awal yang sudah memiliki alur aplikasi utama.
Tahap lanjutan yang disarankan:
